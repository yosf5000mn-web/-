# رقميات للتكنولوجيا

موقع عربي لإدارة القطع البديلة والحسابات الجاهزة، مبني باستخدام Flask وSQLite.

## التشغيل على الكمبيوتر

1. ثبّت Python 3.10 أو أحدث.
2. افتح مجلد المشروع في Terminal / CMD.
3. نفّذ:

```bash
python -m venv venv
# Windows:
venv\\Scripts\\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000`.

**الدخول الأول:** اسم المستخدم `admin` وكلمة المرور `123123`.
غيّر كلمة المرور وأنشئ حساب مدير آمن قبل نشر الموقع.

## النشر على GitHub وRender

1. أنشئ مستودع GitHub وارفع جميع ملفات هذا المجلد.
2. في Render اختر New > Blueprint ثم اربط مستودع GitHub.
3. سيقرأ Render ملف `render.yaml` وينشئ خدمة الويب وقرصاً دائماً لقاعدة البيانات.
4. بعد النشر افتح رابط الموقع وسجّل الدخول.

> القرص الدائم في Render ضمن خطة مدفوعة. لا تحذف إعداد `disk` إذا أردت الاحتفاظ بالبيانات بعد إعادة النشر.

## الوظائف

- مدير افتراضي ينشأ تلقائياً عند أول تشغيل.
- إضافة موظفين وتفعيل/تعطيل حساباتهم.
- إضافة الشاشات واللزقات مع الأجهزة المتوافقة.
- إضافة حسابات بريد جاهزة تملكها أو لديك إذن بتوزيعها.
- يطالب الموظف بالحساب، ثم يضغط «تم تسجيل الدخول» ليختفي من قائمة المتاح.
- الوضع الليلي والنهاري.

## تنبيه أمني

هذا النظام يعرض بيانات حسابات بريد جاهزة يضيفها المدير؛ لا ينشئ حسابات Google ولا يتصل بخدمات Google. استخدم فقط حسابات تملكها أو لديك تصريح صريح بتوزيعها. بيانات الحسابات تحفظ في قاعدة البيانات، لذلك لا تضف حسابات شخصية أو حساسة. قبل الاستخدام الفعلي، غيّر كلمة مرور المدير الافتراضية واستخدم `SECRET_KEY` عشوائياً وقوياً.
