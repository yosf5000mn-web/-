# Y-N STORE — HTML / CSS / JavaScript

نسخة ثابتة بدون Python أو Flask. يمكن رفعها إلى GitHub Pages.

## تشغيل
افتح `index.html` بالمتصفح. لتغيير كلمة المرور عدّل السطر `const PASSWORD = "ChangeMe123!";` داخل `app.js`.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديداً.
2. ارفع `index.html` و`style.css` و`app.js` و`README.md` إلى جذر المستودع.
3. من Settings → Pages اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`.
4. احفظ وانتظر ظهور رابط الموقع.

## مهم جداً حول الخصوصية والبيانات
- كلمة المرور الموجودة في JavaScript ليست حماية حقيقية؛ يمكن لأي زائر فحص ملفات الموقع وتجاوز شاشة الدخول.
- الفواتير تحفظ في `localStorage` على المتصفح والجهاز نفسه فقط. لا تنتقل تلقائياً إلى جهاز آخر، وقد تضيع عند حذف بيانات المتصفح.
- استخدم زر «نسخة احتياطية» لتنزيل ملف JSON بشكل دوري، وزر «تصدير CSV» لفتح الفواتير في Excel.
- GitHub Pages يستضيف ملفات ثابتة فقط ولا يوفر قاعدة بيانات خاصة أو تسجيل دخول آمن. إذا كانت بيانات المحاسبة سرية فعلاً وتريد الدخول من عدة أجهزة، تحتاج خدمة خلفية/قاعدة بيانات مثل Supabase مع سياسات وصول صحيحة.
