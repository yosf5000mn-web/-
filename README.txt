رقميات - نسخة محلية أولية
=========================
1) ثبّت Python 3 من python.org مع تفعيل Add Python to PATH.
2) شغّل install.bat مرة واحدة.
3) شغّل run.bat لفتح الموقع على http://127.0.0.1:5000
4) دخول المدير: افتح "دخول المدير" وكلمة المرور الافتراضية 123123.
5) من لوحة الإدارة أضف القطع المتوافقة وحسابات Gmail الجاهزة.
6) لتشغيله تلقائياً عند دخول ويندوز شغّل startup.bat مرة واحدة.

ملاحظات مهمة:
- هذه نسخة محلية على جهاز واحد، وليست جاهزة للنشر العام على الإنترنت.
- لا تضع حسابات مهمة أو كلمات مرور حساسة في نسخة تجريبية. قاعدة البيانات المحلية تحتوي بيانات الحسابات كما هي.
- غيّر كلمة مرور المدير والمفتاح السري قبل أي استخدام فعلي أو مشاركة مع أجهزة أخرى.
- حركة "إنشاء حساب" تمثل تجهيز حساب جاهز من مخزون المتجر؛ لا تنشئ حساب Google حقيقياً.
- زر "تم تسجيل الدخول" يعلّم الحساب كمستخدم ويمنع عرضه لزبون آخر.
- البيانات محفوظة في ملف raqmiat.db بجانب app.py.
